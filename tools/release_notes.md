# 发布说明

每个版本的说明都写在这里，`tools/release.py` 发版时会取同名小节（`## v<版本>`）当 Release 正文。
上面这段是文件说明，不会出现在 Release 里。

## v1.0.4

全新「连接手机」向导：一个按钮完成配对和连接，设备列表直接点「连接」，报错全部换成通俗中文。

- 无线连接 / USB 连接分成两个标签页，无线为默认页，界面更清爽。
- 设备列表合并「当前在线、附近新发现、以前连过」三类设备，每台一个「连接」按钮；以前连过的手机换了端口也能自动找到并重连。
- 设备名显示手机的商品名（如「一加 13」），不再是一串看不懂的乱码编号。
- 首次配对只需填配对码：手机停在「使用配对码配对设备」页面时，电脑会自己找到手机的 IP 和端口，你只要照着手机输入 6 位配对码，点一次「连接手机」就完成配对、找端口、连接。IP 和端口分成两个输入框（中间自动补冒号、两侧留白一致），空框里有灰色提示：IP 举例、端口几位、配对码几位；提示和输入的文字都垂直居中。
- 连接成功后窗口中央显示浅绿色「连接成功」提示，1 秒后配置窗口自动消失、投屏窗口出现，不用再手动关窗。
- 已连接的设备不再显示「连接」按钮，设备行也不再可点（点它不会发起连接，避免误触重复投屏）；重新连接前会先结束旧的投屏进程，不会再冒出第二个「裸」投屏窗口。状态标签统一为「已连接/新发现/离线」，设备行文字垂直居中；鼠标悬停只让按钮变色（与「连接手机」大按钮同款深色），设备行不再整行高亮。
- 离线（以前连过但手机现在没开无线调试）的设备不再显示「连接」按钮——点了必然连不上；现在它显示的是「配对」按钮，点了会展开配对面板、把 6 位配对码填进去就能重新连上（新的 IP:端口 会自动问设备）。完全看不出是哪台设备的离线行（没地址、名字也只是「无线设备」）不再显示，列表更清爽。手机重新打开无线调试后，列表每 3 秒自动刷新，几秒内它自己就变回「新发现」，点一下即可投屏。刷新完不再在底部报「找到 N 台设备」，列表本身就是答案。
- 「新发现」的设备如果以前没跟这台电脑配对过，按钮显示「配对」：点它会把手机的 IP 和端口自动填好，你只要照着手机上的「使用配对码配对设备」页面输入 6 位配对码，再点「连接手机」。
- 底下那块「首次配对」输入区平时收起来了，界面只剩设备列表；设备不在列表里（或一台都没发现）时点「设备不在列表里？手动配对」展开，一台都没发现时会自动展开。已配对过的设备点「配对」后只显示配对码一个框（自动问到的 IP:端口 以小字显示在框上方，不用看也不用改）。列表固定显示 6 台（展开配对区时 4 台），设备更多时用鼠标滚轮翻。配对区收起时窗口也跟着变矮，底部不留大片空白；展开后的操作提示会一直留在底部，不会被每 3 秒的自动刷新清掉。
- 修复：设备名偶尔显示成 `MoDo9u` 这类编号——现在优先显示记住的设备名（如「一加 13」），其次「无线设备 IP」，不会再把 mDNS 串号当中的乱码。
- 修复：同一台手机在列表里出现两行（一行「已连接」带地址、一行「已连接」没地址）——现在按 IP 合并成一行，并补上 IP:端口。
- 修复：点「新发现」设备的「连接」失败——手机每次开关无线调试都会换端口，现在连接失败时会自动用刚查到的端口重试一次。
- 修复：配对连接后投屏窗口没出现（投屏进程启动即退出）——电脑记下的 ip:端口 与 adb 实际报的设备编号不一致时，会改用 adb 报的编号启动投屏。
- 连接出错时窗口内直接显示中文原因和建议（如「端口不对，请核对手机无线调试页面」），不再弹英文错误框。
- 断开连接或重新配对导致投屏结束时，不再弹「投屏进程已退出」的错误框：投屏安静收尾，托盘图标提示「已断开」，想再看从托盘「连接手机…」重连即可。
- 修复：配对成功却提示「没找到连接端口」。现在配对成功后等连接端口的时间更长（10 秒），端口找到但连不上时会直接说明真实的失败原因；如果手机不广播连接端口（例如路由器开了客户端隔离），可以把「无线调试」主页上的端口填进端口框、**配对码留空**直接点「连接手机」，跳过配对直接连接。
- 向导窗口使用魔芋应用图标；已连接/离线标签紧跟设备名显示；主题绿色更浅更柔和；修复鼠标划过 tab/刷新按钮时内容区闪烁跳动（离屏双缓冲绘制）。
- 修复：配对花了几分钟才成功时，会误弹「投屏窗口 60 秒仍未出现」的错误提示（实际投屏正常）。

安装与连接手机的步骤见 README：https://github.com/zzm6666/moyu-mobile-screen-mirroring#readme
