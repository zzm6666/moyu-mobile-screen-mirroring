# 发布说明

每个版本的说明都写在这里，`tools/release.py` 发版时会取同名小节（`## v<版本>`）当 Release 正文。
上面这段是文件说明，不会出现在 Release 里。

## v1.0.6

- 修复：扫码配对实际上没执行 adb pair——二维码里的 10 位口令被当成「6 位配对码」校验掉了，手机就一直停在「正在配对设备」。

- 修复：扫码后一直停在「等待设备扫码」、设备一直「正在配对设备」——等待扫码的任务之前一启动就误以为被取消，根本没去问设备。

这一版加上扫码配对：不用抄 6 位码，手机扫一下电脑上的二维码就完成配对和连接。

- 配对面板右上角多了「配对码 / 二维码」切换，默认仍是配对码；点「二维码」当场生成一张码，手机用「无线调试 → 使用配对码配对设备 → 扫描二维码」扫一次即可，电脑自动配对并连接。
- 二维码模式下没有输入框和「连接设备」按钮，窗口自动变高摆下码；切回「配对码」或点「收起」会立刻停止等待扫码。
- 二维码右栏有「刷新」，随时换一张新码（120 秒没扫到就停，提示重试）。
- 一台设备都没发现时不再自动展开面板，点下方「设备不在列表里？手动配对」才展开。
- 修复：切到二维码模式后窗口下方会留一条黑边（窗口变高时那一块没被重画）。

## v1.0.5

这一版把「连接设备」向导又打磨了一轮：更少的按钮、更少的状态标签、更短的等待，配对和投屏各自该出现的地方也各归各位。

- 首次配对只要填 6 位配对码：手机停在「使用配对码配对设备」页面时，电脑会自己问出 IP 和配对端口，不用你抄 IP、也不用管端口。配对面板平时收起来，需要时点设备行的「配对」或底部的「手动配对」展开。
- 点「配对」只填 IP、**不填端口**：列表里的端口是投屏用的连接端口，配对端口是手机每次打开配对页重新随机的另一个端口——上一版把两者搞混，导致「只填配对码」必然失败，这一版修掉了。
- 设备列表只保留「已连接」一种标签；没连上的设备按钮一律是「配对」，不会再出现点了注定失败的「连接」。
- 以前连过、但手机现在没开无线调试的设备不再显示在列表里（既连不上也配不了）；列表空着时会提示上次连过的设备，手机一开「无线调试」它自己就回来了。
- 列表固定 6 行高，设备多了用滚轮翻；一台都没发现时自动展开配对面板；面板收起时窗口跟着变矮，不再在底部留一大片空白。
- 向导开着时每 3 秒悄悄刷新一次列表，不再打断你的操作，也不会把你刚看到的提示清掉。
- 同一台手机不再重复出现两行，设备名也不会再显示成 `MoDo9u` 这种串号；手机换了 IP 或端口也能自动认回来。
- 配对面板只属于「无线连接」页：切到「USB 连接」页不会再露出 IP / 端口 / 配对码输入框。
- 投屏窗口直接出现在屏幕右下角，不再先在左上角闪一下再跳过去。
- 断开或重新配对导致投屏结束时不再弹「投屏进程已退出」；投屏程序启动后自己退出时会说清原因，并把 scrcpy 自己的输出留在 `%APPDATA%\魔芋\scrcpy.log`。
- 大按钮和窗口标题里的「连接手机」改为「连接设备」——设备不一定是手机。

## v1.0.4

全新「连接设备」向导：一个按钮完成配对和连接，设备列表里没连上的行点「配对」填 6 位码，报错全部换成通俗中文。

- 无线连接 / USB 连接分成两个标签页，无线为默认页，界面更清爽。
- 设备列表合并「当前在线、附近可见、以前连过」三类设备：已连接的行显示「已连接」，其余能操作的行只有一个「配对」按钮——没连上就得先配对，不会再出现点了注定失败的「连接」。手机换了端口也能自动找到并重连。
- 设备名显示手机的商品名（如「一加 13」），不再是一串看不懂的乱码编号。
- 首次配对只需填配对码：手机停在「使用配对码配对设备」页面时，电脑会自己找到手机的 IP 和端口，你只要照着手机输入 6 位配对码，点一次「连接设备」就完成配对、找端口、连接。IP 和端口分成两个输入框（中间自动补冒号、两侧留白一致），空框里有灰色提示：IP 举例、端口几位、配对码几位；提示和输入的文字都垂直居中。
- 连接成功后窗口中央显示浅绿色「连接成功」提示，1 秒后配置窗口自动消失、投屏窗口出现，不用再手动关窗。
- 已连接的设备不再显示「连接」按钮，设备行也不再可点（点它不会发起连接，避免误触重复投屏）；重新连接前会先结束旧的投屏进程，不会再冒出第二个「裸」投屏窗口。状态标签只保留「已连接」一种（没连上的行不挂标签），设备行文字垂直居中；鼠标悬停只让按钮变色（与「连接手机」大按钮同款深色），设备行不再整行高亮。
- 以前连过、但手机现在没开无线调试的设备不再出现在列表里：那种状态既连不上也配不了，留着只是个点不动的按钮；手机一开「无线调试」它自己就会回到列表。列表空着时底部会提醒「上次连过的「一加 13」现在没开着无线调试」，不会让人以为记录丢了。手机重新打开无线调试后，列表每 3 秒自动刷新，几秒内它自己就变回「新发现」，点一下即可投屏。刷新完不再在底部报「找到 N 台设备」，列表本身就是答案。
- 没连上的设备（列表里能看到、但还没连上）按钮一律是「配对」：点它会把手机的 IP 填好（**端口不填**：列表里的端口是投屏用的连接端口，配对端口是手机「使用配对码配对设备」页面上显示的另一个随机端口，电脑会在配对时自己去问设备），你只要照手机那一页输入 6 位配对码，再点「连接手机」。
- 底下那块「首次配对」输入区平时收起来了，界面只剩设备列表；设备不在列表里（或一台都没发现）时点「设备不在列表里？手动配对」展开，一台都没发现时会自动展开。已配对过的设备点「配对」后只显示配对码一个框（自动问到的 IP:端口 以小字显示在框上方，不用看也不用改）。列表固定显示 6 台（展开配对区时 4 台），设备更多时用鼠标滚轮翻。配对区收起时窗口也跟着变矮，底部不留大片空白；展开后的操作提示会一直留在底部，不会被每 3 秒的自动刷新清掉。
- 修复：设备名偶尔显示成 `MoDo9u` 这类编号——现在优先显示记住的设备名（如「一加 13」），其次「无线设备 IP」，不会再把 mDNS 串号当中的乱码。
- 修复：同一台手机在列表里出现两行（一行「已连接」带地址、一行「已连接」没地址）——现在按 IP 合并成一行，并补上 IP:端口。
- 修复：连接时用到的端口过期导致失败——手机每次开关无线调试都会换端口，现在连接失败时会自动用刚查到的端口重试一次。
- 修复：配对连接后投屏窗口没出现（投屏进程启动即退出）——电脑记下的 ip:端口 与 adb 实际报的设备编号不一致时，会改用 adb 报的编号启动投屏。
- 连接出错时窗口内直接显示中文原因和建议（如「端口不对，请核对手机无线调试页面」），不再弹英文错误框。
- 断开连接或重新配对导致投屏结束时，不再弹「投屏进程已退出」的错误框：投屏安静收尾，托盘图标提示「已断开」，想再看从托盘「连接手机…」重连即可。
- 修复：配对成功却提示「没找到连接端口」。现在配对成功后等连接端口的时间更长（10 秒），端口找到但连不上时会直接说明真实的失败原因；如果手机不广播连接端口（例如路由器开了客户端隔离），可以把「无线调试」主页上的端口填进端口框、**配对码留空**直接点「连接手机」，跳过配对直接连接。
- 向导窗口使用魔芋应用图标；已连接/离线标签紧跟设备名显示；主题绿色更浅更柔和；修复鼠标划过 tab/刷新按钮时内容区闪烁跳动（离屏双缓冲绘制）。
- 修复：配对花了几分钟才成功时，会误弹「投屏窗口 60 秒仍未出现」的错误提示（实际投屏正常）。
- 投屏窗口直接出现在右下角：不再先闪一下屏幕左上角那个没有操作栏的「裸」窗口。
- 手机还在线、投屏却启动失败时会给中文提示（不再一声不响），并把 scrcpy 自己的报错写进 `scrcpy.log`。
