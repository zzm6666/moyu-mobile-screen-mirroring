# 发布说明

每个版本的说明都写在这里，`tools/release.py` 发版时会取同名小节（`## v<版本>`）当 Release 正文。
上面这段是文件说明，不会出现在 Release 里。

## v1.0.4

全新「连接手机」向导：一个按钮完成配对和连接，设备列表直接点「连接」，报错全部换成通俗中文。

- 无线连接 / USB 连接分成两个标签页，无线为默认页，界面更清爽。
- 设备列表合并「当前在线、附近新发现、以前连过」三类设备，每台一个「连接」按钮；以前连过的手机换了端口也能自动找到并重连。
- 设备名显示手机的商品名（如「一加 13」），不再是一串看不懂的乱码编号。
- 首次配对只需填配对码：手机停在「使用配对码配对设备」页面时，电脑会自己找到手机的 IP 和端口（找到后自动填进输入框），你只要照着手机输入 6 位配对码，点一次「连接手机」就完成配对、找端口、连接。IP 和端口分成两个输入框（中间自动补冒号、两侧留白一致），空框里有灰色提示：IP 举例、端口几位、配对码几位；提示和输入的文字都垂直居中。
- 连接成功后窗口中央显示浅绿色「连接成功」提示，1 秒后配置窗口自动消失、投屏窗口出现，不用再手动关窗。
- 已连接的设备不再显示「连接」按钮，设备行也不再可点（点它不会发起连接，避免误触重复投屏）；重新连接前会先结束旧的投屏进程，不会再冒出第二个「裸」投屏窗口。状态标签统一为「已连接/新发现/离线」，设备行文字垂直居中；鼠标悬停只让「连接」按钮变色（参照刷新按钮：浅绿底+绿字），设备行不再整行高亮。
- 连接出错时窗口内直接显示中文原因和建议（如「端口不对，请核对手机无线调试页面」），不再弹英文错误框。
- 断开连接或重新配对导致投屏结束时，不再弹「投屏进程已退出」的错误框：投屏安静收尾，托盘图标提示「已断开」，想再看从托盘「连接手机…」重连即可。
- 修复：配对成功却提示「没找到连接端口」。现在配对成功后等连接端口的时间更长（10 秒），端口找到但连不上时会直接说明真实的失败原因；如果手机不广播连接端口（例如路由器开了客户端隔离），可以把「无线调试」主页上的端口填进端口框、**配对码留空**直接点「连接手机」，跳过配对直接连接。
- 向导窗口使用魔芋应用图标；已连接/离线标签紧跟设备名显示；主题绿色更浅更柔和；修复鼠标划过 tab/刷新按钮时内容区闪烁跳动（离屏双缓冲绘制）。
- 修复：配对花了几分钟才成功时，会误弹「投屏窗口 60 秒仍未出现」的错误提示（实际投屏正常）。

安装与连接手机的步骤见 README：https://github.com/zzm6666/moyu-mobile-screen-mirroring#readme

- `Moyu-1.0.4-portable.zip`：便携版，解压后双击 `安装.cmd` 或直接运行 `魔芋.exe`

## v1.0.3

改进：没连上手机时不再显示空的投屏窗口，只显示「连接手机」向导；连接成功后才出现投屏窗口。

- 启动时如果没找到手机，界面上只有连接向导，不再出现一片空白的投屏窗。
- 手机连上（或从断线恢复）后，投屏窗口自动出现。
- 投屏过程中手机断线，投屏窗口自动收起，不会把最后一帧画面留在桌面上。
- 没连手机时点托盘图标，直接打开连接向导，而不是弹出一个空的投屏窗。

修复：点击最小化别的应用窗口时，魔芋的窗口偶尔会被系统激活的窗口盖住（层级下降）。
