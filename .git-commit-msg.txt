fix(wizard): 设备列表不再重复、名字不再出现串号，离线按钮沿用刷新样式

用户反馈的六项（m03008）：

- 「连接」按钮 hover 不统一：新发现行沿用「连接手机」大按钮的深浅主色，
  离线行改成和右上角「刷新」同一套（白底灰框灰字 / hover 浅绿底绿字）。
- 设备名偶发显示 MoDo9u：mDNS 串号分支不再取中间段，改「记住的名字 →
  无线设备 IP」；旧配置里把串号当名字存的记录也一律过滤。
- 同一台手机列成两行：merge_devices 按 IP 统一去重，历史里同时留着
  ip:port 和 mDNS 串号的旧记录只留 mDNS 那条；拿不到 mDNS 地址时用
  「两行 wifi 在线」兜底合并；refresh 里再自己组播问一次 mDNS 补地址。
- 「新发现」点连接失败：端口每次开关无线调试都会变，connect_only 失败时
  用 mDNS 最新端口重试一次。
- 配对后投屏窗口不出现：向导记住的 ip:port 与 adb 报的串号不一致时，
  resolve_serial 统一成 adb 口径（mirror_app 起 scrcpy 前也校验）。
- list_online 兼容 adb devices -l 形态（transport_id 不再漏设备）。

顺带：刷新设备列表时点「连接手机」不再被丢掉（排队到刷新结束再跑）；
remember_device 不再把串号/ip:port 当名字存，ip:port 记录并进同一台手机
的 mDNS 记录。测试 144 用例全绿（connect_ui/mdns_browse/wizard 冒烟/mirror）。
