# 魔芋 · 把手机屏幕变成桌面小窗

把 Android 手机的画面装进 Windows 桌面上一块小窗里：白色半透明操作栏、圆角、窗边一圈淡阴影，可以拖、可以缩放，鼠标直接操作手机。

不用解锁手机就能看消息、刷视频、看通知；窗口只占屏幕一角，不挡事。

![魔芋](tools/app_icon.png)

## 功能

- **桌面小窗投屏**：无边框小窗，默认 60 帧，画面铺满整个视频区，不留黑边
- **鼠标反控**：在窗口里点击、滑动就是操作手机
- **白色半透明操作栏**：左边圆形应用图标 + 标题「魔芋」+ 右边关闭按钮，连接缝处一条 1 像素白色分隔线
- **圆角与阴影**：整个窗口四角圆角，窗口外一圈很淡的阴影（不压到视频画面）
- **拖动与缩放**：按住操作栏拖动整个窗口；拖四周边缘或角落改变大小，自动保持手机画面比例；拖动不会超出屏幕，贴到底部继续放大时窗口会整体上移让位
- **横竖屏跟随**：手机转横屏，窗口自动变成横向并保持比例；初始位置在屏幕右下角，与右、下边距一致
- **托盘常驻**：单击托盘图标显示 / 隐藏窗口，右键有菜单；运行时不占任务栏、不抢焦点
- **不打扰**：最小化别的窗口时，魔芋不会跳出来抢最前
- **连接向导**：扫码式的「无线调试」配对，或 USB 直连；配好之后每次启动自动重连
- **自动更新**：每天后台检查一次，有新版本会提示并引导安装

## 系统要求

| 项 | 要求 |
|---|---|
| 电脑 | Windows 10 / 11（64 位） |
| 手机 | Android 11 及以上，需要打开「开发者选项」里的无线调试或 USB 调试 |
| 网络 | 电脑和手机在同一个 Wi-Fi，或用 USB 数据线连接 |

## 下载与安装

到 [Releases](../../releases) 页面下载最新版本，二选一：

**① 安装版（推荐）**

1. 下载 `Moyu-Setup-<版本>.exe`
2. 双击运行，按提示下一步即可（默认安装到 `%LOCALAPPDATA%\Programs\魔芋`，**不需要管理员权限**，安装过程中可以改目录）
3. 装好后桌面和开始菜单都有「魔芋」快捷方式

**② 便携版（免安装）**

1. 下载 `Moyu-<版本>-portable.zip`，解压到任意目录
2. 双击 `安装.cmd` —— 效果和安装版一样（复制到用户目录、建快捷方式、在「设置 → 应用」里可以卸载），同样不需要管理员权限
3. 或者什么都不装，直接双击里面的 `魔芋.exe` 当绿色版用

> 程序没有代码签名，第一次运行时 Windows 可能提示「Windows 已保护你的电脑 / 未知发布者」，点「更多信息 → 仍要运行」即可。

> 个别电脑（实测装了腾讯电脑管家的 Windows 11）双击安装版会在第一步报
> `Setup was unable to create the directory "...\Temp\is-XXXX.tmp". Error 5: 拒绝访问。`
> 这是本机安全软件拦住了安装程序，和安装包本身无关。遇到这种情况请改用便携版 + `安装.cmd`。

## 第一次连接手机

连接需要一次性配对，之后每次启动都会自动连，不用再输入任何东西。

### 无线连接（推荐）

1. 手机：**设置 → 关于手机 → 连点「版本号」7 次**，回到设置就能看到「开发者选项」
2. 进入 **开发者选项 → 无线调试**，把它打开
3. 点「**使用配对码配对设备**」，记下弹窗里的 `IP 地址:端口` 和 **6 位配对码**
4. 电脑上右键托盘里的魔芋图标 → 「**连接手机…**」→ 填 `IP:端口` 和配对码 → 点「**配对**」，成功后再点「**连接**」

> 注意：配对用的端口和连接用的端口**不是同一个**。程序会在配对成功后自动找到正确的连接端口；如果网络屏蔽了自动发现，就手动填手机「无线调试」页面上显示的那个「IP 地址和端口」，再点「连接」。

### USB 连接

用数据线连电脑 → 手机上点「允许 USB 调试」→ 在连接向导里选中这台设备 → 点「用这台设备」。

### 日常启动

直接双击「魔芋」，程序会按「在线设备 → 上次用的地址 → 自动发现」的顺序重连，一般不用管。

手机关机或重启后，系统会关掉「无线调试」，到开发者选项里重新打开即可（**不需要重新配对**）。

## 使用

| 操作 | 效果 |
|---|---|
| 按住**操作栏**拖动 | 移动整个窗口 |
| 拖**窗口边缘 / 角落** | 改变窗口大小（保持画面比例，不会拖出屏幕） |
| 点操作栏右边的 **×** | 隐藏窗口（不退出程序，收进托盘） |
| **单击托盘图标** | 显示 / 隐藏窗口 |
| **右键托盘图标** | 菜单：隐藏投屏、连接手机…、检查更新…、退出 |
| 点一下窗口 | 被别的窗口盖住时，回到最前面 |

## 自动更新

- 程序每天检查一次新版本，**只有真的有新版本才弹窗**，断网或没有配置时不会打扰你
- 想立刻检查：右键托盘图标 →「检查更新…」
- 有新版本时按提示确认，程序会自动下载并启动安装（会先关掉正在运行的旧版本），装完重新打开即可

## 卸载

- **安装版**：设置 → 应用 → 魔芋 → 卸载（或从开始菜单里右键卸载）
- **便携版脚本安装**：运行安装目录里的 `卸载.cmd`

卸载时会询问是否一并删除配置和日志（在 `%APPDATA%\魔芋` 目录，删掉后下次连接需要重新配对）。

## 常见问题

**Q：提示找不到设备 / 连不上手机？**
确认手机和电脑连的是**同一个 Wi-Fi**（不是手机的移动数据），手机的「无线调试」开关是打开的；如果之前配对过、但手机重启了，重新打开「无线调试」开关即可。也可以直接用 USB 线连一次。

**Q：配对成功了，但点「连接」失败？**
绝大多数情况是端口填错了：配对弹窗给的是**配对端口**，连接要用「无线调试」页面上显示的那个「**IP 地址和端口**」。在向导里重新填这个端口，再点「连接」。

**Q：双击安装包没反应 / 报 Error 5？**
是安全软件拦住了安装程序。改用便携版，解压后双击 `安装.cmd`；或者干脆直接双击 `魔芋.exe` 用。

**Q：Windows 提示「未知发布者」？**
程序没有购买代码签名证书，属于正常提示：点「更多信息 → 仍要运行」。

**Q：安全软件报毒、甚至把文件删了？**
没有签名的程序容易被误判。把安装包或安装目录加入安全软件的信任区后再装；程序本身只在自己的安装目录、`%APPDATA%\魔芋` 和注册表的「卸载信息」里写东西。

**Q：找不到托盘图标？**
Windows 默认把新程序的图标收进任务栏右下角的「显示隐藏的图标」里，点开就能看到魔芋，可以把它拖到外面固定显示。

**Q：画面有点卡 / 不够清晰？**
尽量用 5GHz 的 Wi-Fi、让手机和电脑靠近路由器；手机后台应用多的时候也会掉帧。

**Q：必须开「开发者选项」吗？**
是的。投屏和反控依赖手机的调试接口，而打开它只能通过开发者选项（无线调试 / USB 调试）。只需开一次，之后日常使用不需要再动它。

**Q：手机关屏后还投屏吗？**
可以，但部分机型锁屏后会降低刷新率或断开连接，以实际表现为准。
